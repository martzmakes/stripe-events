# Support

This library is maintained by one person in spare time and is in maintenance mode.

- **Bugs and questions:** open a GitHub issue. Issues are triaged in a weekly
  slot. There is no response-time or fix-time commitment.
- **Pull requests:** welcome within the scope in CONTRIBUTING.md.
- **No private support, consulting, or SLA** is offered through this repository.
- Issues with no activity for 90 days may be marked stale and closed. If the
  repository sees no commits for 12 months it will be archived with a notice.
